                            Estratégia de Candidatura
                        

                        

                            
                            

                                
Personalizar currículo com IA

                                

                                    Para envios por e-mail, adapta somente o objetivo profissional e as habilidades técnicas com base na vaga; o restante do currículo permanece igual ao PDF base.
                                

                            

                        

                        

                            
                            

                                
Usar apenas currículo base

                                

                                    Desabilita a geração de novos currículos pela IA. Todas as candidaturas usarão somente o PDF base enviado acima, sem nenhuma adaptação automática. Ideal para economizar tokens da API.
